# D-158 · Outside services not yet under D-058 are named on the privacy page now and gated later

**Date:** 2026-11-12  
**Status:** in force

**Question:** Some outside companies can receive a member's details from portal pages and are not yet under the outside-services rules (D-058): what3words, an address look-up service, embedded video players, code libraries loaded from outside servers, the robot check on forms, and error monitoring. What before the first install?

**Answer:** Name them now, gate later. Before the first install each one is listed truthfully on the privacy page (what it receives and why); putting them under the installation, organisation and member on/off rules comes after the first install.

**Rules out:** Gating every one before the first install; leaving them unnamed.

**Where:** #808 — the privacy page. Related: D-058, D-072, D-073, D-156.
