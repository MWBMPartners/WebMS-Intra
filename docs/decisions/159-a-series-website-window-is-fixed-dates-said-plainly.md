# D-159 · A series' public-website window is one set of fixed dates, said plainly on the form

**Date:** 2026-11-12  
**Status:** in force

**Question:** A repeating series can be shown on the organisation's public website between two dates. One fixed window is stored for the whole series. Keep it, or store it relative to each date?

**Answer:** Keep one fixed window for the whole series and say so plainly on the form ("the same dates apply to every date in the series"). The owner also asked for an issue to enhance or change this later: #1016.

**Rules out:** Storing the window relative to each date before the first install.

**Where:** #847 (enhancement later: #1016) — the series form. Related: D-057, D-077.
