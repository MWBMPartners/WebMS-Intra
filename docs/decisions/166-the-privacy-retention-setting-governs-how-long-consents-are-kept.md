# D-166 · The privacy data-retention setting governs how long consent records are kept

**Date:** 2026-11-12  
**Status:** in force

**Question:** D-163 kept the unused "privacy data retention days" setting and gave it a job. Which job?

**Answer:** How long consents are kept: it controls how long the record of each member's agreement to the privacy notice is kept after it is replaced or the member leaves.

**Rules out:** Making it a general default for every other keeping period.

**Where:** #934 — the consent records and their clear-out. Related: D-163.

---

*One decision per file, under `docs/decisions/`, so that every assistant and
every person reads the same record. Never edited — a decision taken again is
a NEW file that names the one it supersedes. See `docs/decisions/README.md`.*
