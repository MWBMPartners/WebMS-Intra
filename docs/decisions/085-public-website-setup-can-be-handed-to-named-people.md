# D-085 · Setting up the public website can be handed to named people, in the first release

**Date:** 2026-11-07  
**Status:** in force

**Question:** setting up the public website (the organisation's public address, which
websites may frame it, the "check my set-up" button) is done on a new Admin → Public
website page that only a global administrator can open. Should the first release also
let that administrator hand the job to named people (#493)?

**Answer:** **yes, in the first release.** The owner, 7 November 2026, choosing this over
the recommendation to leave it for later. Built as a re-pointable permission (D-017),
held by default by the global administrator only.

**Rules out:** deferring delegation to a later issue.

**Where:** #493 (P3). Related: D-017, D-077.
