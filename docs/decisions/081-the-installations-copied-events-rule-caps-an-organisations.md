# D-081 · The installation's rule for copied-in events caps an organisation's

**Date:** 2026-11-07  
**Status:** in force

**Question:** D-080 lets both the installation's and an organisation's global
administrator choose how copied-in events reach the public website — one box per
subscribed calendar (looser: everything from that calendar at once) or one tick per
event. If the installation chooses one tick per event, may an organisation still choose
one box per calendar (#493)?

**Answer:** **no — the installation's choice caps the organisation's.** An organisation
may choose the same rule or the stricter one, never the looser. The owner, 7 November
2026, choosing the recommended option, because the two administrators may be different
people (D-013, D-058).

**Rules out:** each organisation choosing freely whatever the installation chose.

**Settles:** the open point D-080 left.

**Where:** #493. Related: D-013, D-058, D-080.
