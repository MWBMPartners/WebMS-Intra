# D-219 · The care case member list stays as built for the pilot

**Date:** 2026-11-17  
**Status:** in force

**Question:** (#1108) the care case form lists every member of the organisation, including people who hide their name in the directory and, with several organisations, the hosting administrator. Should anything change?

**Answer:** the owner chose: leave it as it is for the pilot. It matches other staff pickers and a care worker must be able to open a case about anybody. The issue stays open for a search box on large organisations and for hiding the hosting administrator.

**Rules out:** hiding directory-hidden members from the care list.

**Where:** `Site::membersForPicker()`; #1108.

**Supersedes:** nothing.
