# D-127 · Members see where their small group meets next

**Date:** 2026-11-11  
**Status:** in force

**Question:** a group's meetings were only a record of meetings already held, seen by leaders. Should members be
able to see where the group meets next (for example "next Tuesday at the Smiths'")?

**Answer:** yes, and it is built now as part of #809, not deferred. What a member sees of the place follows the
group's existing "who can see the meeting address" setting, and a map only where that home's host has agreed
(D-120, D-124).

**Rules out:** deferring the schedule to a later issue; showing members a home address the group's address setting
would hide from them.

**Where:** #809 — small groups. Related: D-123, D-124.
