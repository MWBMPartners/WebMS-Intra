# D-213 · Switching an account off (unticking Active) does not count as the member leaving

**Date:** 2026-11-17  
**Status:** in force

**Question:** (#934, package 2h) an administrator can untick Active to switch a whole account off; that may be a pause (#1086). Should it count as the member leaving for clearing their consent records?

**Answer:** the owner chose: no. Only Offboarding records a leaving date (D-211); a switched-off account is not treated as having left, so a pause never starts a deletion clock.

**Rules out:** a second date on the account; deleting consent records because an account was paused.

**Where:** #934 / package 2h.

**Supersedes:** nothing.

**Related:** D-211, D-212.
