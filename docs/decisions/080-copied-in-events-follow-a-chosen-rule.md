# D-080 · Copied-in events reach the public website by a rule each level chooses

**Date:** 2026-11-07  
**Status:** in force

**Question:** events copied in from an outside calendar (#514) reach the website through
one "show these on the website" box per subscribed calendar. D-057 says public content is
chosen one item at a time. Which applies to copied-in events (#493)?

**Answer:** **both, as a setting: either one box per subscribed calendar, or one tick per
copied event — chosen by the installation's global administrator, and also by an
organisation's global administrator.** The owner, 7 November 2026 ("Both options,
configurable by installation global admin, and also org global admin").

**What it does NOT settle:** whether an organisation may choose the LOOSER rule (one box
per calendar) when the installation has chosen one tick per event. D-058's "strictest
level wins" and D-013's limit rule both point to the installation's choice capping the
organisation's; asked separately rather than assumed.

**Rules out:** only one of the two rules being available.

**Where:** #493 (P1 or a package of its own). Related: D-013, D-057, D-058, #514.
