# D-086 · What the foyer slideshow shows is a tiered setting

**Date:** 2026-11-07  
**Status:** in force

**Question:** the noticeboard's foyer slideshow (a screen in the building showing posters
on a loop) — once posters have a "show on the public website" tick, should it show only
public posters, or every poster (#493)?

**Answer:** **either, as a setting, tiered:** the installation's global administrator
sets what is permitted, and an organisation's global administrator chooses within that.
The owner, 7 November 2026 ("Either, configurable, with the same tiered configurable
approach allowing an installation global admin to set what is permitted, followed by an
org level global admin…").

**How the tiers combine** (the reading this record takes, following D-013, D-058 and
D-081): "public posters only" is the stricter choice. If the installation permits only
that, an organisation cannot choose "every poster"; if the installation permits both, the
organisation chooses. Default: public posters only, the safe direction, since anyone
walking in can read the screen.

**Rules out:** one fixed behaviour for every installation.

**Where:** #493 (P2). Related: D-013, D-058, D-081.
