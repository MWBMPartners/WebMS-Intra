# D-082 · Only websites an organisation lists may show its public pages in a frame

**Date:** 2026-11-07  
**Status:** in force

**Question:** one way to show portal content on an organisation's own website is a
frame — a window of the portal's page inside the other website's page. Which websites
may do that (#493)?

**Answer:** **only websites the organisation lists.** Each organisation types in its own
websites' addresses, and the portal tells browsers to refuse a frame anywhere else. The
owner, 7 November 2026, choosing the recommended option.

**Rules out:** allowing any website to frame the public pages.

**Where:** #493 (the public door's headers, P3/P4). Related: D-056.
