# D-163 · The unused privacy data-retention setting is kept and given a real job

**Date:** 2026-11-12  
**Status:** in force  

**Question:** A setting "privacy data retention days" is stored and editable but nothing uses it, and it is part of the fingerprint that decides whether a member must agree to the privacy notice again. Remove it, or make it do something?

**Answer:** Make it do something. What it governs is a further decision, asked of the owner on #934 and recorded separately when answered.

**Rules out:** Removing the setting.

**Where:** #934. Related: the consent fingerprint.

---

*One decision per file, under `docs/decisions/`, so that every assistant and
every person reads the same record. Never edited — a decision taken again is
a NEW file that names the one it supersedes. See `docs/decisions/README.md`.*
