# D-172 · The single-gift ceiling is configurable at installation and organisation level

**Date:** 2026-11-12  
**Status:** in force

**Question:** A single gift is capped at 10,000.00 in every currency, which is very different across currencies. What should the cap be?

**Answer:** Configurable at installation and organisation level, the installation's value capping the organisation's (the rule for every limit).

**Rules out:** A fixed ceiling in code; removing the ceiling.

**Where:** #992 — the giving entry handlers, `Portal\Core\SettingLimit`. Related: D-139.
