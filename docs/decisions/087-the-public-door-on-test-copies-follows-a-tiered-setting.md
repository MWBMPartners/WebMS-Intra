# D-087 · Whether the public door on test copies is open to anybody is a tiered setting

**Date:** 2026-11-07  
**Status:** in force

**Question:** the portal has test copies (the `alpha` and `beta` channels) beside the
live one. Should the public-website door on a test copy work for anybody on the internet
— hidden from search engines — so an embed can be tried on a real website, or for
signed-in testers only (#493)?

**Answer:** **both, as a setting, tiered:** the installation's global administrator sets
the ceiling (what is permitted), and an organisation's global administrator chooses
within it. The owner, 7 November 2026 ("Again, both, configurable with tiered global
admin ceiling config").

**How the tiers combine** (the reading this record takes, as D-086): "signed-in testers
only" is the stricter choice and caps an organisation's. When open, every answer from a
test copy's door tells search engines not to list it, whatever is chosen.

**Rules out:** one fixed behaviour for every installation.

**Where:** #493 (P4). Related: D-013, D-058, D-086.
