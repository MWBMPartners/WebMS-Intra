# D-169 · A pending event suggestion cannot be published before it is approved

**Date:** 2026-11-12  
**Status:** in force

**Question:** A visitor's suggestion waits as "pending" until approved (which e-mails the visitor, D-134). What if an administrator publishes it directly?

**Answer:** Refuse: publishing a pending suggestion is refused with a message to approve it first, so moderation and the approval e-mail always happen.

**Rules out:** Treating a publish as an approval.

**Where:** #965 — the event status writers and `Portal\Core\EventSuggestions`. Related: D-134.
