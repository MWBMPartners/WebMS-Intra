# D-013 · For a LIMIT, the installation's value wins

**Date:** 2026-10-29  
**Status:** in force

**Question:** may an organisation raise a limit above what the installation
allows?
**Answer:** never. Three tiers — code, then installation, then organisation —
each able to tighten the one above and none to loosen it. Refuse the number with
the reason; never clamp it quietly.
**Rules out:** enforcing it only in the form; resolving "not chosen" to the
built-in default.
**Where:** `Portal\Core\SettingLimit`; `.claude/CLAUDE.md` → "One install, many
organisations".

**Issue:** [#752](https://github.com/MWBMPartners/WebMS-Intra/issues/752) —
the standing issue for decisions that are not about a feature.
