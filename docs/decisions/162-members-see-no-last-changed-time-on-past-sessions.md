# D-162 · Members see no "last changed" time on a past attendance session

**Date:** 2026-11-12  
**Status:** in force  

**Question:** Members see no figures for past attendance sessions (D-109). A session's page also shows when it was last changed. Should members also not see that time on past sessions?

**Answer:** Hide it too: members see no "last changed" time on a past session; administrators and the chosen role still see it.

**Rules out:** Showing members when a past session was last changed.

**Where:** #930 — the attendance session pages. Related: D-106, D-109.
